# Linko manual test checklist

- [ ] Install APK; app opens to Linko auth (dark teal UI, not Kharcha/Docs look)
- [ ] Set server URL to LAN server; Save
- [ ] Register user A; Register user B (second phone or second browser profile)
- [ ] Search A→B by phone; open chat
- [ ] Send text both ways; see ticks (✓ then ✓✓)
- [ ] Typing indicator appears
- [ ] Online / last-seen updates
- [ ] Send image, document, voice note; peer can open/play
- [ ] Voice call: both hear audio; UI shows encrypted call
- [ ] Video call: both see video when camera permitted
- [ ] Reject / hang up works
- [ ] Log out / log in with PIN works
- [ ] Airplane mode: reconnects when back online
